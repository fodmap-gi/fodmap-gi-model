# fodmap-gi-model

This repository contains the **data processing and modeling work** for the FODMAP–GI Chatbot project.

### Focus
- Cleaning and standardizing food and symptom data  
- Healthcare domain–driven preprocessing of meal logs  
- Association Rule Mining (Apriori) to identify ingredients associated with GI symptoms

### Scope
This repository covers the **data and machine learning layer only**.  
The frontend UI is implemented in a separate repository.

### Tech Stack
- Python, Pandas, NumPy  
- mlxtend (Apriori, association rules)  
- Jupyter Notebook  

### Structure
- `cleanData.ipynb` — data cleaning  
- `preProcessing.ipynb` — domain-based preprocessing  
- `model.ipynb` — association rule mining  

> Note: This repository focuses on analysis and experimentation rather than production deployment.
